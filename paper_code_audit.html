Top Findings

✅ Checkpoint-free public release scope adopted

The public repository now contains source, one reported configuration, a generic trainer launcher, and focused tests. Pretrained weights are intentionally excluded. ImageNet values remain explicitly supported at record level rather than described as public checkpoint replay.

🟠 E1. Closest matched DTEM baseline is absent

The main table still has no DTEM accuracy at the 392-patch target. A literature value from a different patch size or protocol is not a replacement. Run a declared matched protocol or narrow the comparison language and remove the unfinished primary-table row before submission.

🟠 E2. Accuracy–latency–memory frontier is unmeasured

Existing timing records use random weights and nonuniform ToMe attention settings. They cannot fill the primary table. Measure dense, DTEM, ToMe, PiToMe, and MergeNet checkpoints in one environment and harness before making any efficiency-frontier claim.

🟠 E3. Two named method components lack causal ablations

Mass-aware log(mass) key bias and full-grid recovery are central components, but their inference-only interventions remain blank. Run both on the final checkpoint and report score deltas.

🟡 M1. Headline ImageNet comparison is single-seed

The three-seed CIFAR evidence supports the locality mechanism, not the final ImageNet accuracy gap. Add seeds 43/44 for dense and MergeNet, or consistently label ImageNet values single-seed and avoid significance language.

🟡 M2. Historical run environment differs from release lock

The release lock is torch 2.6.0/CUDA 12.4; historical paper runs record torch 2.7.1/CUDA 11.8. The difference is now documented, but exact numerical reproduction should preserve the historical environment or quantify drift.

✅ PiToMe omission from the primary table was fixed

The existing 392-patch full-validation result, 81.742%, is now included beside ToMe and labeled post-training. This avoids a selective-table appearance without inventing a new measurement.

2026-09-23 Campaign Package Recheck

C1. Raw summaries and supplied logs remain numerically consistent

The packet contains 24 raw runs and 3,560 summary rows: 23 target-complete schedules and one abandoned 140/150 weight-decay probe. The independent verifier matched 3,354 rows to supplied EMA log events, found 206 summary-only rows, and found zero metric mismatches after the documented attempt-resolution rules.

C2. Stage-7 ingestion is digest-checked and reproducible

The incremental importer verifies the archive SHA-256, copies both Stage-7 summaries byte-for-byte, preserves the pre-resume initialization arguments, records the missing first-launch log boundary, and regenerates the paper tables from the curated records.

C3. Package narrative files are stale

The top-level README.md still says 18 run directories and incorrectly classifies the 384/512 px fine-tunes as global batch 256 with 5,004 optimizer steps. Raw launcher records show effective global batch 1,024 and 1,251 optimizer steps. Paper-side protocol records use the launcher values.

C4. Stage-8 status is not backed by packaged raw data

STATUS.md and _build/runs_analysis.json include a running s8_mn_softtopk_off_150e entry, but the archive contains no corresponding raw run directory. The paper excludes Stage 8 and counts only the 24 runs with delivered summaries.

C5. The package is record evidence, not a replay bundle

No trained weights are present. Under the revised release scope this is intentional: the package supports summary/log provenance, while public checkpoint replay is not a delivery requirement.

Paper Internal Consistency

P1. Checkpoint policy is now consistent

sections/setup.tex and sections/discussion.tex now state that trained weights are outside the public-release scope and describe the ImageNet evidence as record-level provenance rather than public replay.

P2. Abstract claim strength corrected

The abstract now reports the negative matched-budget ordering and explicitly withholds an accuracy–efficiency frontier claim until trained-checkpoint systems and component measurements exist.

P3. Summary-only portions need receipts

206 of 3,560 ImageNet summary rows lack a matching log row, including the first 105 epochs of the host-migrated initialization run. Preserve checkpoint digests and reevaluate affected endpoints if these results remain in the paper.

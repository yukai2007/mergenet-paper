\section{Routing Visualization}
\label{sec:pending-routing-population}

The visual examples are selected before inspecting the router.
We choose one ImageNet validation image per class using a fixed
SHA-256 ordering of image paths, giving 1,000 images in total. From
this set, the main figure shows the first correctly classified
and the first misclassified image under the same ordering. Passive
tracing is checked against untraced predictions, top-$K$ indices,
and token mass; the check gives \pendingresult{parity summary}.
If no error occurs in the selected set, the selection rule uses two
correct cases.

The main figure pairs actual step-3 donor-to-receiver transport
edges with the final 392 carrier locations for each selected image.
The population figure summarizes per-image routing distances
over all six steps and the selection frequency of each original
$28\times28$ patch location across the 1,000 images. Carrier
markers denote selected slots, not semantic regions. Mean route
distance is \pendingvalue{} patches, and the selection-frequency pattern
is \pendingresult{population interpretation}.

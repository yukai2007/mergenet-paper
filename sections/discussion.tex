\section{Discussion}

The physical bottleneck provides a fixed-size interface between local
image processing and global latent reasoning. The carrier count can be
changed at inference, and the resulting accuracy curves show how one
checkpoint behaves across budgets. Higher-resolution fine-tuning further
raises accuracy, while the resolution-transfer results show the value of
adapting the model before operating on a substantially larger patch grid.

The full execution cost depends on more than the latent sequence length.
Local encoding, routing, and recovery still process full-grid information.
Compilation brings the measured batch-64 \mn{} latency close to ToMe on
the A100, whereas the separate 384-pixel H20 benchmark shows lower latency
than dense DeiT-S/8 with higher memory use. These observations concern
the tested implementations and operating points. The classification
results use individual training runs, and the synthetic efficiency
measurements characterize model execution separately from checkpoint accuracy.

\section{Experimental Protocol}
\label{sec:setup}

\paragraph{Training and evaluation.}
We train on ImageNet-1K and report EMA top-1 on its 50,000-image validation
split. Main 224-pixel runs use AdamW for 150 or 300 epochs with global batch
1,024, cosine decay, five warmup epochs, weight decay 0.05, label smoothing
0.1, Mixup 0.8, CutMix 1.0, RandAugment, random erasing 0.25, and no teacher.
The matched geometry controls use learning rate $5\times10^{-4}$; the selected
\mn{} configuration uses $7.5\times10^{-4}$. Thus geometry comparisons are
recipe matched, whereas the final dense--\mn{} comparison uses each selected
configuration. Full arguments and the run inventory are in
Appendix~\ref{app:recipe}.

The 384-pixel models fine-tune the 300-epoch EMA weights for 30 epochs; the
512-pixel models add 15 epochs. All retain effective global batch 1,024 via
gradient accumulation. We report both the best and final EMA values because
best-checkpoint selection uses the same validation split. A supplied packet
contains 21 complete and two interrupted ImageNet schedules. We recompute
endpoints by header name from 3,365 contiguous summary rows and cross-check
3,264 rows against supplied logs; missing-log rows remain summary-only. The
company checkpoints were not transferred, so this is a record audit rather
than an independent checkpoint replay.

\paragraph{Compression comparisons.}
The main table fixes 392 final patches at 224 pixels. ToMe and PiToMe are
applied after training to the dense checkpoint, while \mn{} is trained with
its native bottleneck. The budget sweep evaluates the complete validation set
at five budgets. These rows compare deployable checkpoints; they do not
isolate the routing rule under identical training. A separate CIFAR-100 study
trains two selectors $\times$ four routing geometries $\times$ three seeds for
200 epochs. Its preregistered endpoint is epoch-199 EMA top-1.

\paragraph{Timing.}
Historical 224- and 384-pixel latency records use synthetic inputs and random
weights; one later ToMe sweep also disables proportional attention. We report
these only as architecture diagnostics. The primary table leaves latency and
memory blank until dense, matched DTEM, ToMe, and \mn{} are measured from
trained checkpoints with identical preprocessing, precision, batch, attention
policy, token hooks, and CUDA-event timing. The same collaborator packet will
supply two inference-only component scores and passive routing traces; no
checkpoint transfer is requested.

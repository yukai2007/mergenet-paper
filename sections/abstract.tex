\begin{abstract}
Modern visual recognition requires models to capture both fine-grained image
detail and long-range context. Vision transformers meet these needs by
representing images as patch tokens and modeling their interactions, but
retaining every token across layers becomes costly at high resolution. Token
merging reduces this cost by consolidating redundant tokens. Yet its success
depends on both learning which tokens to combine without losing task-relevant
information and on turning those decisions into a physically shorter
sequence. DTEM learns the merging policy with dedicated merge embeddings and a
continuous relaxation. However, its soft training path retains every token
slot, so it learns merge decisions without actually shortening the sequence;
hard merging is still required. \mn{} closes this gap with a local-to-latent
architecture. Differentiable routing learns where information should flow and
consolidates it; fixed-budget selection then physically shortens the sequence
before global reasoning. We make this compression trainable with differentiable budgeted selection and efficient in execution with fused kernels for mass-aware attention over merged tokens. We evaluate \mn{} for image
classification on ImageNet-1K, using DeiT-S as the dense baseline and
comparing against DTEM and ToMe at matched token budgets. \mn{} achieves
\textbf{[MERGENET-TOP-1]}\% top-1 accuracy under
\textbf{[TOKEN-COMPRESSION]}$\times$ token compression, compared with
\textbf{[DEIT-TOP-1]}\% for DeiT-S, \textbf{[DTEM-TOP-1]}\% for DTEM, and
\textbf{[TOME-TOP-1]}\% for ToMe. Under matched
\textbf{[HARDWARE/BATCH/PRECISION]} settings, \mn{} reduces inference latency
by \textbf{[LATENCY-REDUCTION]}\% and peak memory by
\textbf{[MEMORY-REDUCTION]}\% relative to DeiT-S. These results demonstrate
that combining learned information routing with an explicit compression
boundary yields a better accuracy--efficiency trade-off for image
classification.
\end{abstract}

\section{Differentiable Spatial Routing and Physical Compression}
\label{sec:method}

\subsection{Local-to-latent architecture}
For patch size $p$, let $N=(H/p)(W/p)$ be the number of patch slots, excluding
the protected CLS token. The main model uses $p=8$, width 384, six heads, six
local blocks, and six latent blocks. At $224^2$, each local block processes
784 patches plus CLS. Patch queries attend within a one-dimensional band of
16 token positions on either side; the CLS query attends globally. The local
encoder first produces $H^{(1)},\ldots,H^{(6)}$. Six soft transport steps then
update the final slots, each using a metric derived from the corresponding
local-layer output. These steps retain all slots. Only the subsequent gather
reduces the sequence before recovery and global latent attention, as shown in
Figure~\ref{fig:architecture}.

\subsection{Spatial mass routing}
Spatial eligibility limits where mass can move while leaving edge strengths
learned. Index patch $i$ by its original-grid coordinate $u_i$. Each routing
step
partitions patches into disjoint donor and receiver sets $A_\ell,B_\ell$;
training samples a partition for each image, while evaluation alternates a
deterministic odd/even partition across steps. CLS is excluded. Donor $i$
may route only to
\begin{equation}
 \mathcal E_i^{(\ell)}(R)=\{j\in B_\ell:\|u_i-u_j\|_2\le R\}.
 \label{eq:support}
\end{equation}
The main model uses $R=3$ patch spacings. Coordinates stay tied to original
slots throughout routing, even as features and masses change. The control
geometries are defined in Section~\ref{sec:setup}.

A learned $384\!\to\!64$ projection of $H^{(\ell)}$ produces normalized
metrics $z_i$. Its input gradient is scaled by 0.1 without changing its
forward value. On eligible edges,
\begin{equation}
 s_{ij}=\langle z_i,z_j\rangle/\tau,\quad
 q_{ij}=\frac{\exp s_{ij}}{\sum_{r\in\mathcal E_i}\exp s_{ir}},\quad
 a_{ij}=g_iq_{ij},
 \label{eq:routing}
\end{equation}
with $\tau=1$ in the main configuration. Here $g_i$ is a soft donor weight.
Following
\citet{sujianlin2024topk}, a monotone relaxation applies a data-dependent
threshold $\theta$ after sorting,
\begin{equation}
g_{bi}=F(\alpha\bar e_{bi}-\theta_b),\qquad
\sum_i g_{bi}\approx k_\ell,
 \label{eq:softtopk}
\end{equation}
Here $b$ indexes images, $e_{bi}=\sum_{j\in\mathcal E_i}\exp s_{bij}$ is
the row energy, and
$\bar e_{bi}=e_{bi}/(\max_{b',r}e_{b'r}-\min_{b',r}e_{b'r})$.
The function $F(t)$ is
$1-\frac12e^{-t}$ for $t>0$ and $\frac12e^t$ otherwise; $\theta_b$ is the
per-image threshold, $\alpha=30$, and $k_\ell$ is the scheduled donor budget.
The minibatch-wide range means an image's soft weights can depend on its
batch companions. The released selector has no guard for a zero energy range.
This relaxation replaces serial top-$k$ decisions with a parallel soft mask;
it does not make the later gather indices differentiable. Rows without
eligible receivers have zero assignment.

Each slot carries mass $m_i$, initialized to one. A transport step preserves a
donor feature and transfers a fraction of its mass into receiver features:
\begin{align}
 m'_i&=m_i(1-\textstyle\sum_j a_{ij}), & X'_i&=X_i,\nonumber\\
 m'_j&=m_j+\textstyle\sum_i a_{ij}m_i, &
 X'_j&=\frac{m_jX_j+\sum_i a_{ij}m_iX_i}{m'_j}.
 \label{eq:transport}
\end{align}
The implementation clamps residual fractions and denominators. Donor slots
remain present even when their mass becomes small. Sparse neighbor lists
restrict scored edges, but the released initialization still constructs a
dense adjacency buffer; the support constraint does not establish linear
memory for the complete implementation.

\subsection{Exact budget and recovery}
Soft transport leaves every slot active, so an explicit gather sets the
sequence length processed by later blocks. For compression factor $\lambda$,
the carrier count is
\begin{equation}
 K=N-\left\lfloor N(\lambda-1)/\lambda\right\rfloor.
 \label{eq:budget}
\end{equation}
The model hard-gathers the $K$ largest-mass patches. At $224^2$ and
$\lambda=2$, $N=784$ and $K=392$; the six soft donor budgets are
$(65,65,65,65,65,67)$. A straight-through factor
$1+g-\operatorname{stopgrad}(g)$ on selected features sends gradients to the
continuous scores while hard indices execute the budget; it does not
differentiate the index choice. The selected carriers are ordered by a
detached, mass-weighted center of their flattened source indices. The
protected CLS token is prepended. These carrier queries $Q$ recover
information from the pre-transport full-grid features through
\begin{equation}
 Y=Q+\operatorname{CrossAttn}(Q,H^{(6)},H^{(6)}),
 \label{eq:recovery}
\end{equation}
and six latent blocks process $K$ patches plus CLS. During training, the
classification logits also include an auxiliary contribution from a
soft-selection-weighted average of the full-grid features, with weight at
most 0.05; evaluation uses only the latent CLS logits. This is a logit
contribution, not a separate auxiliary loss.

\subsection{Mass-aware attention and a fused operator}

Carriers represent different amounts of transported mass, which we retain
in latent attention using ToMe's proportional-attention bias~\citep{tome2023}.
For $N_q$ queries and $N_k$ keys, let
$\beta_j=\log m_j$ and $B=\mathbf 1_{N_q}\beta^\top$. Then
\begin{equation}
 \operatorname{Attn}(Q,K,V;m)=
 \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_h}}+B\right)V.
 \label{eq:mass-attn}
\end{equation}
The bias is rank one across query positions. Define
\begin{equation}
 \widehat Q=[Q,\sqrt{d_h}\mathbf1_{N_q}],\qquad
 \widehat K=[K,\beta].
 \label{eq:augmented-qk}
\end{equation}
Using the \emph{original} softmax scale $1/\sqrt{d_h}$ gives
\begin{equation}
 \frac{\widehat Q\widehat K^\top}{\sqrt{d_h}}
 =\frac{QK^\top}{\sqrt{d_h}}+\mathbf1_{N_q}\beta^\top,
 \label{eq:augmented-equivalence}
\end{equation}
so a standard attention kernel realizes the biased logits without
materializing $B$. The explicit scale is essential: using a kernel default
based on the augmented or padded width would not be equivalent.

The released operator pads $d_h+1$ to
$d_{\mathrm{phys}}=8\lceil(d_h+1)/8\rceil$, zero-fills extra query/key
channels, pads $V$ to the same physical width, invokes an unmodified
FlashAttention kernel~\citep{flashattn2022}, and truncates its output to
$d_h$. The reported ImageNet classifier instead applies the same mass bias
through PyTorch's fused scaled-dot-product attention. The separate
FlashAttention-compatible operator has an exact logit identity, but the
current checkpoint results do not establish a latency or peak-memory gain
from using it.

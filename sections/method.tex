\section{Method}
\label{sec:method}

\subsection{Overview}
\mn{} connects differentiable routing to a physically shorter latent sequence
within one forward pass. Given $N$ image patches and a class token, a local
encoder produces full-grid features $H^{(1)},\ldots,H^{(L)}$. Starting from
$X^{(0)}=H^{(L)}$ and unit patch masses, $L$ soft routing steps redistribute
information while retaining every patch slot. A hard gather then selects $K$
patch carriers. The carriers read the pre-transport features through
cross-attention, and a latent encoder followed by a class head produces the
prediction. Figure~\ref{fig:architecture} shows the project schematic; the
evaluated classifier uses its encoder-to-latent path.

\subsection{Spatial mass routing}
Spatial routing restricts where patch information may move without fixing
the routing weights. Patch $i$ keeps its coordinate $u_i$ on the original
two-dimensional grid. At routing step $\ell$, patches are partitioned into
disjoint donor and receiver sets $A_\ell$ and $B_\ell$; the class token
participates in neither set. The eligible receivers for donor $i$ are
\begin{equation}
 \mathcal E_i^{(\ell)}(R)
 =\{j\in B_\ell:\|u_i-u_j\|_2\le R\}.
 \label{eq:support}
\end{equation}
Coordinates remain tied to original slots as features move, so this rule
constrains individual transport edges rather than the model's complete
receptive field.

The routing weights combine learned similarity with a soft donor decision.
A learned projection of $H^{(\ell)}$ yields normalized metrics
$z_i^{(\ell)}$. For eligible pairs, we compute
\begin{equation}
 s_{ij}^{(\ell)}
 =\langle z_i^{(\ell)},z_j^{(\ell)}\rangle/\tau,\qquad
 q_{ij}^{(\ell)}
 =\frac{\exp s_{ij}^{(\ell)}}
 {\sum_{r\in\mathcal E_i^{(\ell)}(R)}\exp s_{ir}^{(\ell)}}.
 \label{eq:routing}
\end{equation}
The row energy
$e_i^{(\ell)}=\sum_{j\in\mathcal E_i^{(\ell)}(R)}
\exp s_{ij}^{(\ell)}$ enters a threshold-based smooth top-$k$
operator~\citep{sujianlin2024topk}. Given the step budget $k_\ell$, it
produces a continuous donor weight $g_i^{(\ell)}$; the transport weight is
$a_{ij}^{(\ell)}=g_i^{(\ell)}q_{ij}^{(\ell)}$ on eligible edges and zero
elsewhere; a donor with no eligible receiver has zero assignment. The smooth
weights provide a gradient path from the task loss to the routing metrics.

Soft transport updates mass and receiver features without removing the
donor slot. With patch feature $X_i$ and mass $m_i$, one step gives
\begin{align}
 m'_i&=m_i\left(1-\sum_j a_{ij}\right),&
 X'_i&=X_i,\nonumber\\
 m'_j&=m_j+\sum_i a_{ij}m_i,&
 X'_j&=\frac{m_jX_j+\sum_i a_{ij}m_iX_i}{m'_j}.
 \label{eq:transport}
\end{align}
The sums cover eligible edges in the current donor--receiver partition.
The implementation stabilizes residual fractions and denominators, while
all patch slots remain present for the next routing step.

\subsection{Physical bottleneck and recovery}
A hard gather turns the soft routing state into the shorter sequence used by
later blocks. For compression factor $\lambda$, the patch-carrier budget is
\begin{equation}
 K=N-\left\lfloor N(\lambda-1)/\lambda\right\rfloor.
 \label{eq:budget}
\end{equation}
Let $\mathcal I=\operatorname{TopK}(m^{(L)}_{\rm patch},K)$ contain the indices
of the $K$ largest patch masses, ordered before gathering. After normalizing
the routed features,
$\bar X=\operatorname{Norm}(X^{(L)})$, we form the carrier sequence
$C=[\bar X_{\rm cls};\bar X_{\mathcal I}]$. Thus $C$ contains exactly
$K+1$ tokens, including the protected class token, in both training and
inference.

The gather keeps its indices discrete while passing gradients to soft
selection scores. A second smooth top-$K$ operator applied to the final
patch masses gives weights $h_i$. Each selected feature is multiplied by
$1+h_i-\operatorname{stopgrad}(h_i)$, which equals one in the forward pass.
This connects the selected features to the continuous scores without
differentiating the index choice.

Recovery lets the carriers read information still available on the full
grid. Using $H^{(L)}$ as the pre-transport key and value sequence, define
\begin{equation}
 Z=C+\operatorname{CrossAttn}(C,H^{(L)},H^{(L)}).
 \label{eq:recovery}
\end{equation}
The latent encoder processes $Z$, and its class-token output enters the
classification head. Global latent self-attention therefore runs on $K+1$
tokens, while recovery still reads the full-grid features.

\subsection{Mass-aware latent attention}
The selected carriers represent different amounts of transported mass.
Following proportional attention in ToMe~\citep{tome2023}, latent
self-attention adds the log of each carrier mass to its key logit. For
per-head query, key, and value matrices $Q_{\rm a},K_{\rm a},V_{\rm a}$,
head width $d_h$, and selected masses $m_j$, this is
\begin{equation}
 \operatorname{Attn}(Q_{\rm a},K_{\rm a},V_{\rm a};m)
 =\operatorname{softmax}\!\left(
 \frac{Q_{\rm a}K_{\rm a}^{\top}}{\sqrt{d_h}}
 +\mathbf 1\log(m)^\top\right)V_{\rm a}.
 \label{eq:mass-attn}
\end{equation}
The class token retains unit mass. This bias accounts for mass in attention;
its contribution to classification accuracy requires a separate ablation.

The per-key bias can be encoded as one extra query/key dimension. Set
$\widehat Q_{\rm a}=[Q_{\rm a},\sqrt{d_h}\mathbf 1]$ and
$\widehat K_{\rm a}=[K_{\rm a},\log m]$. With the original scale
$1/\sqrt{d_h}$,
\begin{equation}
 \frac{\widehat Q_{\rm a}\widehat K_{\rm a}^{\top}}{\sqrt{d_h}}
 =\frac{Q_{\rm a}K_{\rm a}^{\top}}{\sqrt{d_h}}
 +\mathbf 1\log(m)^\top.
 \label{eq:augmented-equivalence}
\end{equation}
The released FlashAttention-compatible operator implements this identity
after padding the head dimension. The reported ImageNet classifier uses the
same bias through PyTorch's scaled-dot-product attention; the operator
identity alone does not establish a runtime gain.

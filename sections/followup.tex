\section{Efficiency Details}
\label{app:followup}

\paragraph{A100 protocol.}
We measure inference on an A100-SXM4-80GB using randomly initialized
models, device-resident $224\times224$ inputs, inference mode, and fp16
autocast. Each method and batch size runs in a fresh process with 50
warmups followed by five rounds of 200 CUDA-event samples. Latency is
the median of all 1,000 samples and excludes model setup, data loading,
and diagnostic hooks. Memory is the peak allocated or reserved GPU memory.
Dense DeiT-S/8 has 784 patch tokens; each compressed method reaches 392
final patches, excluding CLS. ToMe and PiToMe enable proportional attention.
The software environment is PyTorch 2.6.0 with CUDA 12.4 and timm 0.9.11.

The coefficient of variation of the five round medians is below 0.3\%
for every eager batch-64 measurement. Batch-1 latency is more sensitive
to host scheduling: two independent eager \mn{} runs yield 18.27 and
21.00\,ms. Table~\ref{tab:a100-efficiency} reports both values.

\paragraph{Compiled execution.}
For ToMe, we compile the transformer-block forwards. For \mn{}, we compile
local and latent transformer blocks, cross-attention, and selection and
merge operations, while leaving the enclosing local-encoder forward eager.
Compilation and its initial warmup are excluded from steady-state timing.
The compiled rows in Table~\ref{tab:a100-efficiency} use the same synthetic
input shape and fp16 precision as the eager rows. The 0.02\,ms difference
between compiled batch-64 medians does not establish a meaningful speed
ordering. These timings characterize the implementations independently
of the trained-checkpoint accuracy measurements.

\subsection{High-resolution benchmark}
\label{app:highres-efficiency}

The separate 384-pixel benchmark uses an H20-3e and PyTorch 2.7.1 with
CUDA 11.8. Models have random weights and synthetic fp16-autocast inputs;
\mn{} uses $R=3$ and retains 1,152 of 2,304 patches. The benchmark
uses 30 warmups and 50 measured steps. Training time includes forward,
cross-entropy loss, backward, and an AdamW update; inference measures
forward only. Table~\ref{tab:highres-efficiency} reports both batch sizes.
These measurements describe this high-resolution hardware setup and
are independent of the 224-pixel A100 benchmark.
